## 🎯 درباره لابراتوار

**لابراتوار پروژه‌های درهمی** مجموعه‌ای از ابزارهای متن‌باز و رایگان برای توسعه‌دهندگان وب فارسی است. هدف این پروژه ارائه ابزارهای حرفه‌ای و کاربردی برای بهبود تجربه توسعه وب فارسی می‌باشد.

### چرا لابراتوار درهمی؟

| ویژگی | توضیح |
|-------|-------|
| 🆓 **رایگان** | تمامی پروژه‌ها کاملاً رایگان هستند |
| 📖 **متن‌باز** | کد منبع در GitHub در دسترس است |
| 🇮🇷 **فارسی** | طراحی شده برای جامعه وب فارسی |
| 🔧 **حرفه‌ای** | ابزارهای با کیفیت و کاربردی |
| 🔄 **به‌روز** | پروژه‌ها به‌طور منظم به‌روزرسانی می‌شوند |

## 🚀 پروژه‌ها

### 1. 🔍 Ranko - ابزار سئو

ابزار حرفه‌ای سئو و بهینه‌سازی سایت با **۲۵۱ قاعده** در **۲۰ دسته** مختلف.

| ویژگی | توضیح |
|-------|-------|
| Core Web Vitals | اندازه‌گیری LCP, CLS, FCP, TTFB, INP |
| CLI & Desktop | ابزار خط فرمان و اپلیکیشن دسکتاپ |
| AI Ready | آمادگی برای هوش مصنوعی و GEO |
| Multiple Formats | خروجی JSON, HTML, Markdown, LLM |

🔗 [ranko.nounproject.ir](https://ranko.nounproject.ir) | [GitHub](https://github.com/derhami/ranko)

## 📦 نصب و اجرا

### پیش‌نیازها
- Node.js 18+
- npm یا yarn یا pnpm

### نصب

```bash
# کلون کردن پروژه
git clone https://github.com/derhami/nounproject.ir.git

# رفتن به پوشه پروژه
cd nounproject.ir

# نصب وابستگی‌ها
npm install

# اجرای پروژه در حالت توسعه
npm run dev
```

### ساخت نسخه نهایی

```bash
# ساخت پروژه
npm run build

# پیش‌نمایش نسخه نهایی
npm run preview
```
